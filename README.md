## 无限流量VPS到底是不是不限流量？

先明确一个容易误解的地方：VPS 服务商通常不会让用户无限制占满出口带宽。

所谓“无限流量”通常可能代表以下几种情况：

* 不设置固定月流量数字，但限制带宽峰值；
* 提供较大的月流量额度，普通用户基本用不完；
* 采用共享网络资源，需要遵守服务条款；
* 针对不同线路提供不同流量上限。
